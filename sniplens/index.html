截得下来，也用得起来。

SnipLens 常驻菜单栏，需要的时候出现，完成后回到手头的工作。

截图与标注

框选后直接在原位置标注，调整选区、画箭头或图形、遮挡敏感内容，再复制、保存或贴在屏幕上。

截图识字

图片、PDF 或无法选中的界面，框选后得到可编辑、可复制的文字。可指定语言，失败时增强重试，也可主动选择 Google 云端识别。

静默 OCR

只想摘录时，识别结果直接进入剪贴板，选区旁的灰白对勾提示完成。

随处翻译

翻译截图、其他应用中选中的文字，或自己输入的内容。紧凑浮窗以译文为主，可切换 Apple 系统翻译、Google 翻译或自定义服务。

从画面到文字，少一步切换。

在屏幕上框选内容，识别结果即可复制；需要进一步处理时，还能在结果窗口修改原文并翻译。

快捷键按功能配置，截图标注、保存、贴图和翻译窗口操作都可设置自己的按键。

首次打开时被 macOS 阻止？

当前安装包尚未经过 Apple 公证。确认文件来自本页后，在“系统设置 → 隐私与安全性”中选择“仍要打开”。首次截图和划词翻译时，会分别引导屏幕录制与辅助功能授权；从系统设置返回后自动刷新状态，授权尚未生效时提供恢复说明。输入和粘贴翻译无需这两项权限。

文字由你决定去哪里。

默认由 macOS Vision 在本机识别，macOS 26+ 可选择本地文档识别。只有主动选择 Google OCR 时才上传当前截图；Apple 系统翻译在本机处理，Google 翻译与自定义翻译服务只接收文字。

Google 识别与翻译需配置自己的 API 密钥并启用结算，费用以服务商规则为准；密钥保存在钥匙串。SnipLens 不自动保存截图或翻译历史；只有你主动保存图片时才写入磁盘。截图框选目前限于单个显示器，识别更适合横排单栏文字。
